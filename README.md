# Scripture Reader

Build a web app called "Scripture Reader" — a Bible reading app.

Core features:
- A clean, modern home screen with a verse-of-the-day card
- A Bible reader that lets users select from multiple versions/translations (e.g. KJV, NIV, ESV, NLT, AMP) via a dropdown selector
- Users can browse by Book > Chapter > Verse, with a searchable book list (Old & New Testament grouped separately)
- A search bar to search scripture by keyword or reference (e.g. "John 3:16")
- Bookmark/favorite verses feature, saved to the user's profile
- Highlight and add personal notes to verses
- Light and dark mode toggle
- Mobile-responsive design with a bottom nav bar (Home, Read, Search, Events, Profile)

Use a warm, calm color palette suited to a faith-based app (soft blues, creams, gold accents). Use clean typography optimized for reading long text.
